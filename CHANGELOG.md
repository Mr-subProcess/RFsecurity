# Changelog

## 0.6.0 — Cellular assurance modules

- Added passive cell-identity anomaly auditing for exported cell metadata.
- Added RX-only IQ interference-indicator analysis with bounded FFT windows.
- Added sanitized SMS/PBX gateway log auditing with keyed-HMAC tokens and fan-out/rate checks.
- Integrated new CLI commands and Telecom menu items.
- Added unit tests for the three new security-monitor classes.
- No transmit, jammer, rogue-cell, subscriber-identifier harvesting, OTA injection, bulk messaging or bulk calling capability was added.

## 0.5.0

- Added HackRF RX capture, IQ analysis, offline mutation testing and Android device support.
